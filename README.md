# mybash

Реализация bash на C с поддержкой интерактивного режима, пайпов, фоновых заданий и истории команд.

## Возможности
- Запуск внешних программ и встроенных команд (`cd`, `exit`, `jobs`, `fg`, `bg`, `history` и др.).
- Конвейеры `|` и `|&`, перенаправления ввода/вывода/ошибок (`>`, `>>`, `<`, `2>`, `2>>`, `2>&1`).
- Фоновые задания (`cmd &`), управление ими через `jobs`, `fg`, `bg`.
- Подстановки `$?`, `$$`, `$!` и переменных окружения в аргументах.
- История команд с навигацией стрелками и сохранением в `~/.my_shell_history`.
